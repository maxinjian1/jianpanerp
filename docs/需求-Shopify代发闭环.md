# 需求：批发商 → Shopify 代发闭环（2026-10-15 起草，待用户确认）

## 目标
1. 清空 Shopify 店铺现有商品。
2. 从批发商 kuajingyifan.com（用户有账号，已完全授权采集）抓取商品 → 文案日语化 → 图片用中国 AI 重制 → 按 **批发价 +15%** 上架 Shopify。
3. 客户在 Shopify 下单 → 系统到批发商下单并填客户收货信息 → 支付 → 回填物流单号到 Shopify → 闭环。

- 已连接的 Shopify 店：**LECOCO ITALY**（anetmc.com，Basic 套餐，JPY），**47 个商品**（LECOCO 童车系列，部分 ACTIVE 部分 ARCHIVED）。用户给的后台链接 store `0scqav-e7` 是否就是这家，**待确认**。
- kuajingyifan.com：云端容器出站白名单不含该域名，技术栈待 Windows 侧探测（是否有 API / CSV 导出 / 需登录）。
- AI：文案 → GLM-5.3-Flash（已通）；**图片重制需要图像模型**（GLM-5.3-Flash 只能看图不能生图），待定：6kpro 是否提供图像模型，或开阿里云百炼（万相 / Qwen-Image-Edit）。

## 流程设计
```
批发商站 ──(Playwright 登录采集)──► 商品原始数据(中文/图片/批发价/库存)
      │                                   │
      │                        GLM 翻译+合规词检查 ──► 日语标题/五点/描述
      │                        图像模型 去水印/白底/日文卖点图
      ▼                                   ▼
   Supplier 表 ◄──────────────────── Shopify 商品(批发价×1.15×汇率，取整)
                                          │
客户下单 ──► Shopify 订单 webhook ──► ERP 生成"待下单"草稿（含客户收货信息）
                                          │  人工一键确认（第一阶段）
                                          ▼
                       Playwright 到批发商站下单 + 填收货地址 + 支付
                                          │
                       抓物流单号 ──► Shopify 标记发货 ──► 客户收到通知
```
个人信息（客户姓名/地址/电话）只在 Windows/V64 本地处理，不发中国 API（符合 CLAUDE.md 决定 1）。

## 实施阶段（确认后）
1. **备份 + 清空**：导出 47 个商品 CSV → 归档/删除。
2. **采集器**（Windows Playwright）：登录 → 遍历分类 → 抓标题/规格/图/价/库存 → 入库 `Supplier*` 表。
3. **上架流水线**：GLM 日语化 + 合规词检查 → 图片重制 → Shopify 建品（含 SKU 映射、价格公式）。先 10 个试跑，看效果再全量。
4. **订单闭环**：Shopify webhook → 待下单草稿 → 人工确认 → Playwright 下单+支付 → 回填单号 → 自动发货标记。
5. **库存/价格同步**：每日比对批发商价格库存，自动调价/下架。

# 乐天 アネットショップ2025 — 出单计划（广告 + 非广告）

> 2026-10-25 起草。前提：批发商 kuajingyifan 同时供货给多家卖家，乐天上会有**同图同款**的竞品。
> 所有花钱的动作（广告预算、优惠券、积分倍率）都先出方案给用户，**用户同意后才开**。数字凡是估算都标「估算」。

## 0. 先认清局面

| 事实 | 含义 |
|---|---|
| 同一批发商供多家，图片和说明来自同一套模板 | 买家看到的是一模一样的商品页；**比价、送货速度、评价、积分** 决定谁出单 |
| 我们定价 = 批发价 ×1.39（含税） | 毛利约 28%（估算）；扣乐天费用约 10〜13%（估算，取决于出店プラン）再扣我们承担的运费 → **低价商品几乎没有广告空间** |
| 全品送料無料、新店 0 评价 | 乐天搜索排序重视 转换率・销量・评价；新店初期靠自然搜索很难 |
| 958 件草稿已上/在上 | 不可能全品投广告，必须**选品投放** |

**结论：先用两周找出「我们比同款竞品便宜或持平、客单价 ≥ 2,000 円」的 30〜50 件，只给这些投 RPP；其余靠活动和积分蹭流量。**

## 1. 乐天的流量入口（按优先级）

| 工具 | 是什么 | 费用模式 | 我们怎么用 |
|---|---|---|---|
| **RPP（楽天プロモーションプラットフォーム）** | 搜索结果页顶部的关键词广告，自动按商品名/关键词匹配 | CPC，月预算最低 5,000 円，单次点击最低约 25 円（估算，以 RMS 显示为准） | 主战场。只投「价格有竞争力」的商品，设商品别出价；每周按 ROAS 除外/加价 |
| **クーポンアドバンス広告** | 带优惠券的 CPC 广告，券额我们出 | CPC + 券 | 用于「同款竞品多、价格打平」的商品，用券制造差价 |
| **お買い物マラソン / スーパーSALE / 5と0のつく日 / ワンダフルデー** | 平台大促，买家集中下单 | 免费参加；需要搭配ポイント変倍或クーポン才有展示 | 每次都报名。新店最容易在大促期间出第一单 |
| **ポイント変倍（店舗ポイントアップ）** | 我们出积分原资（1 倍 = 售价 1%） | 售价 × 倍率 | 新品期对主推 50 件设 2〜3 倍，等出评价后回落 |
| **39ショップ** | 3,980 円以上送料無料 的店 | 免费 | 我们全品包邮，自动符合；确认 RMS 里标志已点亮 |
| **楽天アフィリエイト** | 外部博主带货 | 成交后按料率付 | 保持默认料率，不主动加 |
| **R-Mail / フォローメール** | 购后邮件 | 免费 | 发货后 7 天发「レビューのお願い」，这是积分最高的动作 |
| **TDA（ターゲティングディスプレイ）/ 楽天スーパーDEAL** | 展示广告 / 高返点专区 | 高门槛 | 月销有了再说 |

## 2. 两周启动计划

### 第 1 周：选出能打的商品
1. **同款比价**：用 `tools/market-research/price-check.mjs`（乐天搜索抓前 8 自然结果中位数）跑全部已上架商品（原来只跑 TOP50，改为读乐天发布清单）。输出每件：我们价 / 同款最低价 / 中位数 / 竞品数。
2. **分三档**：
   - **A 档（投放）**：我们 ≤ 同款最低价 ×1.05，且售价 ≥ 2,000 円，且批发商库存 ≥ 10 → 预计 30〜50 件。
   - **B 档（活动）**：价差 5〜15% → 只参加大促 + 积分，不投 RPP。
   - **C 档（放着）**：价差 >15% 或售价 < 1,000 円 → 不花钱；等以后调价或下架。
3. **商品页补强**（A 档优先）：商品名按 `title-check.md` 修正案改（去型号、去违规词、关键词前置）；キャッチコピー填「送料無料 / 当日出荷 / セット内容」；目玉商品设 2〜3 倍积分。
4. RMS 后台确认：39ショップ 标志、あす楽 不开（我们是代发，承诺不了）、配送リードタイム 填实际（批发商出货 + 1 天）。

### 第 2 周：小预算起跑
1. **RPP**：月预算 **30,000 円**（约 1,000 円/天，用户可改），只勾 A 档商品，商品别出价 = 最低出价 ×1.2〜1.5；其余商品除外。
2. **报名最近一次お買い物マラソン**（每月约 2 次）：A 档设 ポイント 3 倍，B 档 2 倍，期间 RPP 日预算 ×2。
3. **首单券**：全店 300 円 OFF（3,000 円以上），成本可控。
4. **评价**：每笔订单发货后第 7 天 R-Mail 请评价（乐天允许请评价，不允许用返点换好评）。

### 每周例行（判断用代码，改动要用户同意）
| 条件（直近 14 日） | 动作 |
|---|---|
| 点击 ≥ 30、0 单 | 从 RPP 除外，查商品页/价格 |
| ROAS < 500%（广告费 >20% 销售额） | 出价 −20%，再差就除外 |
| ROAS ≥ 1000% 且预算用完 | 出价 +10%、提案加预算 |
| 有订单无评价 | 确认 R-Mail 发了没 |

## 3. 损益线（估算，用户确认出店プラン后重算）

以售价 P（含税）、批发价 W = P/1.39 计：
- 乐天费用：システム利用料（スタンダード约 2〜4.5% / がんばれ 3.5〜6.5%）+ ポイント原資 1% + アフィリエイト平均约 1% + 決済 约 3.5% + 安全性・システム 约 0.3% → **合计约 8〜13%**
- 运费：我们包邮，代发运费按批发商报价（小件约 500〜800 円）
- 单件可用于广告的上限 ≈ P − W − 乐天费 − 运费 − 目标利润（10%）

例：P = 3,000 円 → W ≈ 2,158 → 乐天费约 330 → 运费 600 → 目标利润 300 → **可投广告约 0〜600 円/单**，对应 RPP ROAS 下限约 500%。售价 1,500 円以下的商品基本投不起，只能靠活动。

## 4. 用户已决定（2026-10-25）
1. RPP 首月预算 **30,000 円**（约 1,000 円/天）。
2. 积分：A 档（主推 ≤50 件）**3 倍**、其余 1 倍、大促期间全店 **2 倍**。
3. 首单券 **300 円 OFF（3,000 円以上）**。
4. 出店プラン = **がんばれ!プラン**（システム利用料 3.5〜7.0% 按月销分段 + ポイント原資 1% + アフィリエイト約 1〜1.3% + 決済約 2.5〜3.5% + システムサービス利用料 → 合计约 **9〜13%**，估算，以 RMS 请求书为准）。
5. 代发实际出货 **1 天** → 配送リードタイム填「**2 日以内に出荷**」（留 1 天缓冲，周末批发商可能不发；不开 あす楽）。

执行顺序：① `tools/rakuten/price-tier.mjs` 全品比价分档（不花钱）→ ② RMS：配送リードタイム、39ショップ 确认、R-Mail 请评价模板 → ③ RMS：A 档 ポイント 3 倍、首单券 → ④ RMS：RPP 新建キャンペーン 30,000 円/月，只勾 A 档，商品别出价 = 最低出价×1.3 → ⑤ 报名最近一次お買い物マラソン。②〜⑤ 由 Windows 会话在用户登录的 RMS 里操作，付费确认画面停下交给用户。

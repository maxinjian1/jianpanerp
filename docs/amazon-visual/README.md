## 首页「Amazon おすすめ」栏目：需要手动加（app 没有主题写权限，未绕过）

1. Shopify 管理画面 → オンラインストア → テーマ → 当前公开主题的「カスタマイズ」。
2. 左侧「テンプレート」选「ホームページ」，找到「リアルタイムランキング」区块。
3. 在它下面点「セクションを追加」→「おすすめコレクション（Featured collection）」。
4. 标题填「Amazon おすすめ」，コレクション选「Amazonおすすめ」（amazon-osusume），商品数 4〜8、列数和上面的ランキング一致；可开「すべて表示」按钮。
5. 右上「保存」。

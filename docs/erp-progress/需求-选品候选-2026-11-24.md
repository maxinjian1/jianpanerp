# ANET ERP 需求：选品候选（仕入候補）（2026-11-24）

提出：电商会话。实现：ERP 会话。文件版本 v1.1（同日追加：婴儿用品 30 款、睡衣 14 款；新增列 `linked_product`，`source_url` 改为可空）。
用户原话：「把这个放在新开发的系统里，把上次的也放在系统里面」（「这个」= 小香风 1688 候选，「上次的」= 11-21 的衬裙、充电底座两份）；随后「婴儿用品和睡衣的也放进去」（11-13 婴儿用品、11-12 睡衣）。
目的：用户在 ERP 里能看到「调研过哪些货、链接在哪、多少钱、结论是什么、自己定了做不做」，不用再翻 Excel 和聊天记录。

## 0. 原则

1. 候选**不是商品**：不进商品主数据、不进库存、不进利润。用户定了要做并且到货后，才另行登记为商品。
2. 文件里没有的数字留空，页面显示「未確認」，不显示 0。
3. 可重复读入：同一条候选再读一次只更新调研侧的字段，**不覆盖用户在页面上填的「判断」和「メモ」**。
4. 只读取、只记录；ERP 不向 1688 发消息、不下单。

## 1. 文件 ⑦ `sourcing_candidates.csv`（一行 = 一个货源链接）

UTF-8 带 BOM。唯一键：(`source_site`, `source_item_id`)。

| 列 | 必填 | 规则 |
|---|---|---|
| `batch_code` | 是 | 一次调研的编号，例 `SRC-20261124-XXF` |
| `batch_name` | 是 | 调研名称 |
| `research_date` | 是 | 调研日 `YYYY-MM-DD`。价格、销量都是这一天的显示值 |
| `target_channel` | 否 | 打算卖的渠道编号 |
| `group_name` | 否 | 调研内的分组（品类） |
| `reference` | 否 | 依据：对标的 Amazon 商品或搜索词与销量标记，原样文字 |
| `source_site` | 是 | 目前只有 `1688` |
| `source_item_id` | 是 | 货源站的商品编号。只有短链接的写 `qr-<短码>`；没有链接记录的由电商会话编号（例 `rw-20261112-03`） |
| `source_url` | 否 | 链接，页面上要能点开（新标签）。空 = 链接未留存，显示「リンクなし」 |
| `summary` | 是 | 一句话说明 |
| `price_cny` | 否 | 起批价（人民币），搜索卡片显示值 |
| `moq` | 否 | 起订量 |
| `sold_text` | 否 | 已售件数，原样文字（「6,600+」是区间下限，不要转成数字） |
| `repeat_rate_pct` | 否 | 回头率 % |
| `supplier` | 否 | 供应商名 |
| `conclusion` | 否 | 调研结论：`verify`（优先小批量验证）/ `watch`（继续观察并补证）/ `skip`（暂不进入）/ 空（未下结论） |
| `status` | 是 | 初始 `candidate` |
| `linked_product` | 否 | 已经登记成商品的，写 ERP 的商品编号（例 `baby-01`、`rw1688-01`）。页面上显示为可点到该商品页的链接；编号在 ERP 里不存在时只显示文字，不报错 |
| `note` | 否 | 备注（风险、未核实事项） |

## 2. 页面

1. **仕入候補一览**（新页面，菜单放在商品附近）：按调研（batch）分组；列 = 分组、说明、链接、起批价（元）、起订量、已售、回头率、供应商、调研结论、**判断**、メモ。可按调研、调研结论、判断筛选。
2. **判断**由用户在页面上改：未定 / 做 / 不做 / 已拿样 / 已进货。改动记录时间。
3. メモ：用户可写一行文字。
4. 一览顶部显示该调研的说明：调研日、「价格与销量是调研日搜索结果的显示值，详情页未打开的项目起订量为未確認」。

## 3. 验收标准

1. 读入 116 行：婴儿用品 58、小香风 26、睡衣 14、衬裙 13、充电底座 5；五个调研各自成组。
2. 起订量为空的 112 行、起批价为空的 14 行显示「未確認」，不显示 0；链接为空的 5 行显示「リンクなし」。
3. 同一文件读两次，第二次全部「没有变化」。
4. 在页面把一条改成「做」并写メモ，再读入文件，判断和メモ还在。
5. 链接能点开到 1688 对应页面；`linked_product` 有值的 65 行能点到对应商品页。
6. 商品数、SKU 数、库存、首页指标读入前后不变。

## 4. 这一批不做

候选的利润试算（售价、头程、FBA 费用代入）、候选转成商品的一键操作、图片。

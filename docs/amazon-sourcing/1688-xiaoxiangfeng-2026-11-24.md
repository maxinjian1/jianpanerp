## 二、侵权红线（1688 的「小香风」里大量是仿品）

1688 搜「小香风」，标题带「双C / 字母 / 小香家 / 香奶奶 / cf」的占三到五成，主图上直接有双 C 标、CHANEL 包装盒。筛选规则：
- 标题含上述词的全部排除；主图逐张看，有双 C、CHANEL/DIOR 字样、H 标、四叶草（梵克雅宝）的排除。
- 包类基本不能做：翻盖菱格链条包、戴妃包、沙滩托特包都是照着具体款式做的，即使没标也有外观侵权风险。
- Amazon 标题、五点、检索词里**不能写「シャネル」「CHANEL」「シャネル風」**；品牌栏写自有品牌。
- 仿珍珠要写「イミテーションパール / ガラスパール」，不能只写「パール」；「金属アレルギー対応」没有检测报告不能写。

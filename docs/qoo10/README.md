## 做法

- 类目对应：`tools/qoo10/category-map.tsv`（人工逐件对应）；Qoo10 类目全表 `tools/qoo10/template/qoo10-cats.txt`（3,027 个小分类）。

- 选项：乐天的规格 → オプション（最多 2 种选项名；3 轴的把前两轴合并）。**选项价必须在销售价 ±50% 内，且要有 0 円选项** → 自动选能覆盖全部规格的基准价，选不出就按价格带拆成多个商品。

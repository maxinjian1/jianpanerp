# 「安い」アプリ 上架指南（iOS App Store / Google Play）

代码位置：`apps/mobile-yasui/`（Expo SDK 58 / React Native 0.88 / TypeScript，一套代码出 iOS + Android）。
数据源：Shopify Storefront API（公开令牌，只读商品 + Cart API），结账用 Shopify 官方 Checkout（WebView 内打开）。

## 0. 为什么这样做（审核要点）
- **不是纯网页壳**：首页/排行榜/分类/搜索/商品页/购物车全部是原生界面，只有「结账」「法定页面」用 WebView。Apple 审核 4.2（最小功能）对纯 WebView 壳会拒，这样做能过。
- **实物商品**：Apple 3.1.3(e) 允许实物商品用自己的支付（Shopify Checkout），不需要走 IAP。
- **顾客个人信息不经过 App 服务器**：地址、支付只在 Shopify Checkout 页面输入，App 本身只保存一个匿名 cart ID。隐私标签只需申报「購入履歴（Shopify側）」「識別子なし」。
- 日本法规：特商法表記、プライバシーポリシー、返品规定在「マイページ」里都能一键打开，这是审核员会点的地方。

## 2. 开 Storefront API 令牌（Shopify 后台，5 分钟）
AI 工具被 Shopify 禁止创建 Storefront 令牌，必须你手点：
1. Shopify 管理画面 → **設定 → アプリと販売チャネル → Shopify App Store** 搜索 **Headless**（Shopify 官方免费），安装。
2. 打开 Headless → **ストアフロントを追加**，名字 `yasui-app`。
3. 进入该 storefront → **Storefront API** → 权限勾选：`unauthenticated_read_product_listings`、`unauthenticated_read_product_inventory`、`unauthenticated_read_product_tags`、`unauthenticated_write_checkouts`、`unauthenticated_read_checkouts`、`unauthenticated_read_content`。
4. 复制 **Public access token**（公开令牌，可以打进 App，不是机密）。
5. 在 Windows `apps/mobile-yasui/.env` 写入 `EXPO_PUBLIC_STOREFRONT_TOKEN=...`（模板见 `.env.example`）。

替代方案：Dev Dashboard 里现有的 ANET ERP 应用也能加 Storefront API scope 再发布新版本，但 Headless 更简单。

## 4. 云端打包与提交（不需要 Mac）
```powershell
npm i -g eas-cli
eas login
eas init                      # 会把 projectId 写进 app.json 的 extra.eas.projectId
eas build -p android --profile preview    # 先出一个 APK 自测
eas build -p all --profile production     # 正式包：.aab + .ipa
eas submit -p ios --profile production    # 推到 App Store Connect（需先在 ASC 建好 App）
eas submit -p android --profile production  # 推到 Play Console 内部测试轨道
```
- iOS 签名：EAS 会用你的 Apple ID 自动创建证书与 Provisioning Profile，按提示登录即可。
- Android 签名：EAS 自动托管 keystore；Play 端启用「Google Play App Signing」。
- `eas.json` 里 `ascAppId`、`appleTeamId`、`google-play-service-account.json` 按向导填（密钥文件不入 git，已在 .gitignore）。

**隐私政策补充**（加到 anetmc.com 的プライバシーポリシー末尾）：
```
■ スマートフォンアプリ「安い」について
本アプリは、商品情報の取得および購入手続きのために Shopify Inc. のサービスへ接続します。
アプリ自体は氏名・住所・決済情報を収集・保存しません。これらは購入手続き画面（Shopify Checkout）で入力され、Shopify のプライバシーポリシーに従って処理されます。
アプリは端末内に匿名のカート識別子のみを保存します。端末の位置情報、連絡先、写真へのアクセスは行いません。
```
**App Store 隐私标签**：「購入履歴」= 収集する（Shopify 経由、ユーザーに紐づく）、「識別子/位置情報/連絡先」= 収集しない、トラッキング = なし（ATT ダイアログ不要）。
**Play データセーフティ**：同上；「データは転送中に暗号化」= はい、「削除リクエスト」= お問い合わせページ。

# 后端服务启动说明

## 问题修复

已创建符号链接 `dist/main.js` -> `apps/api-core/src/main.js`，让 `nest start --watch` 能找到正确的入口文件。

## 启动方法

### 方法 1：使用 nest start（推荐，支持热重载）

```bash
cd "/Users/maxinjian/Desktop/Japan ERP/apps/api-core"
npm run dev
```

### 方法 2：如果符号链接不工作，手动构建后运行

```bash
cd "/Users/maxinjian/Desktop/Japan ERP/apps/api-core"
npm run build
node dist/apps/api-core/src/main.js
```

### 方法 3：使用 ts-node（需要先安装 nodemon）

```bash
# 先安装 nodemon（在项目根目录）
cd "/Users/maxinjian/Desktop/Japan ERP"
npm install --save-dev nodemon

# 然后修改 package.json 的 dev 脚本为：
# "dev": "nodemon --watch src --exec ts-node src/simple-main.ts"

# 运行
cd apps/api-core
npm run dev
```

## 如果还有问题

1. **检查符号链接：**
```bash
ls -la dist/main.js
```

2. **重新创建符号链接：**
```bash
cd "/Users/maxinjian/Desktop/Japan ERP/apps/api-core"
rm -f dist/main.js
ln -sf apps/api-core/src/main.js dist/main.js
```

3. **或者直接运行编译后的文件：**
```bash
cd "/Users/maxinjian/Desktop/Japan ERP/apps/api-core"
npm run build
node dist/apps/api-core/src/main.js
```

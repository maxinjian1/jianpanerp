# Seller Central 操作チェックリスト（Windows セッションがユーザーの代わりに画面操作する）

前提：`node tools/amazon-listing/seller-central/browser.mjs` で開いたウィンドウに **ユーザー本人がログイン済み**（`status` で loggedIn=true）。
操作は playwright `connectOverCDP('http://127.0.0.1:9222')` で同じウィンドウを使う。**各ステップ完了時に out/sc-shots/ へスクリーンショット**。

**止まってユーザーに渡す条件**：CAPTCHA、ワンタイムコード、本人確認書類の提出、料金が発生する画面、アカウント健全性の警告、法的同意画面。

## A. 配送設定
1. 設定 → 配送設定 → 配送パターン → 「新しい配送パターンを作成」。
2. 名前 **全国送料無料**、出荷作業日数 **1 日**（平日 12 時までの注文は当日出荷）、国内配送：通常配送、全地域 **送料 0 円**、離島含む。お届け日数は既定値。
3. 保存 → 一覧に表示されたことをスクショ。

## B. GTIN 免除（商品コード免除）
1. 在庫 → 商品登録 → 「商品コード免除を申請」。
2. カテゴリーを選択（まず ホーム＆キッチン）、**ブランド名 SARADEMUNT** で申請（ANET は既存ブランドと衝突して不可、2026-10-17 確認）。
3. 商品名と画像が要る場合：`tools/product-images/out/<handle>/final/01-main-amazon.png` と `08-trust.png` を使う。
4. 送信 → 受付番号をスクショ。他カテゴリ（ジュエリー / ベビー / ドラッグストア / ビューティー / 食品・飲料 / 腕時計 / バッグ / おもちゃ / スポーツ / ペット / 家電 / 服 / 工具 / カー用品 / ライト / 家具 / キッチン）も順に同じ手順。

## C. 出品許可申請（6 カテゴリ）
ジュエリー、ベビー、ドラッグストア（ヘルス＆パーソナルケア）、ビューティー、食品・飲料、腕時計。
1. 在庫 → 商品登録 → 検索欄に該当カテゴリの代表商品名 → 「出品許可を申請」。
2. 書類（仕入先の請求書など）を求められるカテゴリは、ユーザーに書類を依頼して止まる。書類不要のカテゴリはそのまま申請。
3. 申請 ID と状態をスクショ。

## D. 在庫ファイルテンプレートの取得
1. 在庫 → アップロードによる一括商品登録 → 「在庫ファイルのダウンロード」。
2. ホーム＆キッチン → 生成 → ダウンロード（.xlsm）。保存先 `tools/amazon-listing/templates/raw/Home.xlsm`。
3. `node tools/amazon-listing/seller-central/extract-headers.mjs tools/amazon-listing/templates/raw/Home.xlsm Home` で「テンプレート」シート 1〜3 行目を `templates/Home.headers.tsv` に出し、表示された feed_product_type 候補とブラウズノードを `category-map.json` の browseNodes に反映。
4. 他カテゴリも分類表の順に同様。

## E. 在庫ファイルのアップロードと結果確認
1. `node tools/amazon-listing/build-inventory-file.mjs build --type Home --limit 10` → out/inventory-Home.tsv。
2. アップロードによる一括商品登録 → ファイルをアップロード → 在庫ファイル（タブ区切り）→ 送信。
3. 「アップロードステータスの確認」で処理レポートをダウンロード → `out/reports/` に保存 → エラー行があればクラウドセッションに全文を渡して修正 → 再アップロード。
4. 10 件がエラー 0 になったら `build --type Home` 全件 → アップロード。以降カテゴリごとに繰り返す。

## やらないこと
- パスワードやワンタイムコードの入力・保存・ログ出力。
- 出品者情報・入金口座・税務情報の画面の変更。
- アカウント設定の変更、出品停止、価格の一括変更。
